# Armv8-A EL2 system register access

`arm-sysregs-el2` provides EL2 register definitions used by the top-level [`arm-sysregs`][1] crate.

See the [`arm-sysregs` repository][2] or [crates.io page][1] for usage, features, licensing, contribution, and project information.

[1]: https://crates.io/crates/arm-sysregs
[2]: https://git.trustedfirmware.org/arm-firmware-crates/arm-sysregs.git
